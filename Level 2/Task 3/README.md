Level 2 - Task 3: K-Means Clustering

Objective
The objective of this task was to apply the K-Means Clustering algorithm to the Iris dataset and group similar flowers into different clusters based on their features.

Dataset
- Iris Dataset

Tools Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

Algorithm Used
- K-Means Clustering

Features Used
- Sepal Length
- Petal Length

Visualization
- Scatter Plot showing the clustered data points.
- Cluster centroids highlighted using "X" markers.

Files Included
- kmeans.py
- iris.csv
- Kmeans_Plot.png
- README.md

Result
Successfully applied the K-Means Clustering algorithm to divide the Iris dataset into three clusters. The scatter plot clearly shows the grouped data points along with the cluster centroids, making it easier to visualize the similarity between different flower samples.
